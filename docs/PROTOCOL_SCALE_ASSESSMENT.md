# Protocol scale assessment — מה נשאר עד «רף הטריליון»

**תאריך:** אוגוסט 2026  
**מטרה:** הערכה כנה — לא תחזית שווי, לא לוח זמנים. רשימת **שערים** (gates) שמפרידים בין «אפליקציה חכמה» לבין **שכבת פרוטוקול** ששוק ומוסדות חייבים.

---

## מה «טריליון» אומר כאן

בדוקטרינה של זכאי (`docs/INFRASTRUCTURE_DOCTRINE.md`) זה **לא** מספר על השקעה. זה מצב שבו:

1. **סמכות צרכנית** (Mandate) היא תקן שמוסדות *חייבים* לתמוך בו כי מספיק משתמשים מגיעים עם זה.
2. **תוצאות מנותקות** (outcome graph) משפרות את הפעולה הבאה בלי לדלוף PII.
3. **חבילות שוק** (ZML / country packs) הן **נתונים מצוטטים**, לא `if (country === "IL")`.
4. **לולאה סגורה** בצד הצרכן: detect → act → prove → fee → share — **בלי מוקד**.

כל PR שלא מחזק לפחות אחד מארבעת אלה — בדרך כלל PR הלא נכון.

## ציון מצב נוכחי (בערך)

| עמוד | מה בנוי בקוד | מה חסר ל«רף פרוטוקול» | ציון |
|------|----------------|------------------------|------|
| **Mandate + JWKS + decide** | מפרט, test vectors, conformance, MCP discovery, מוסדות `/institutions` | מוסדות **חיים** שמאמתים בפרוד; trust registry עם מנפיקים שאינם רק זכאי | **7/10** טכני, **2/10** אימוץ |
| **ZML + 12 שווקים** | קטלוג, evaluate, 76 IL packs, CDN reload | `zakai-packs` כ-repo/CDN רשמי; עומק משפטי מלא מחוץ ל-IL; landing לכל id | **6/10** |
| **Outcome graph** | `StrategyOutcome`, oracle API, fairness scores | **נפח אמיתי** (מינימום דגימה לכל cohort); בלי seed מזויף | **3/10** |
| **לולאת צרכן סגורה** | תיקים, negotiation, SAVED, share OG, widget | PayPlus + SMTP **בפרוד**; עמלה שנגבית בפועל; מייל יוצא לספק | **5/10** |
| **הפצה** | referral, share, SEO, 76 דפי rights | ויראליות **מתועדת** (לא מספרים מומצאים); שותפים עם widget בפרוד | **4/10** |
| **אוטופילוט** | 5 מנועים + crons, שערי אדם | לא auto-merge חוק; לא TikTok בלי מפתחות — **נכון** | **5/10** (מכוון) |
| **כוח קנייה קבוצתי** | intent API בלבד | מכרז חי + משפטים + נזילות — phase 0 בכוונה | **1/10** |

**סיכום במשפט:** יש **שלד פרוטוקול ברמת production-ready**; חסרים **זרימת כסף אמיתית**, **צפיפות outcomes**, ו**לפחות מוסד אחד** שמוכיח verify/decide בקנה מידה.

## שערים לפי סדר עדיפות (CEO)

### שכבה 0 — «אנחנו עסק אמיתי» (ימים–שבועות של founder ops, לא חודשים של קוד)

| שער | למה קריטי | סטטוס |
|-----|-----------|--------|
| מיזוג **PR #71** + deploy טרי | הכל מה שתלוי בפרוד | **ממתין** |
| PayPlus חי | עמלת הצלחה = הכנסה | mock בקוד |
| SMTP חי | SENT אמיתי, לידים, outbox | לרוב ריק |
| preflight + `verify:production-urls` | לא לטעות «חי» כשלא | סקריפט קיים |
| **תיק אחד** מקצה לקצה עם חיסכון מתועד + עמלה | הוכחת לולאה | **חסם מוצרי** |

בלי שכבה 0 — כל שיח «טריליון» הוא סימולציה.

### שכבה 1 — «מנוע צמיחה כנה» (שבועות–חודשים, תלוי בנפח)

| שער | מדד הצלחה |
|-----|-----------|
| 10–50 תיקי SAVED **מתועדים** | קיר `/proofs` לא ריק; fairness scores מתחילים להתמלא |
| שיתוף `/share?amount=` אחרי SAVED אמיתי | OG עם סכום אמיתי בלבד |
| 1–3 פיילוטי verify למוסד (leader wizard) | שם בקיר — **opt-in**, לא לקוח חתום |
| widget אצל שותף אחד | `/partners` → register → validate |

### שכבה 2 — «רשת דו-צדדית» (רבעון–שנה, תלוי רגולציה ונפח)

| שער | מה נפתח |
|-----|---------|
| בנק/ספק אחד מקבל Mandates בנפח | inbound pressure API הופך משכנע |
| מנפיק רשום שני (לא רק זכאי) | trust registry כ-multilateral |
| Outcome graph עם מספיק נקודות per vertical | oracle + negotiation משתפרים **בלי** LLM ממציא |
| ZML packs ב-CDN + גרסאות | מפתחים חיצוניים לא תלויים ב-deploy אפליקציה |

### שכבה 3 — «פרוטוקול כתשתית כלכלית» (שנים, לא מובטח)

| יכולת | תנאי |
|--------|------|
| כוח קנייה / מכרז קבוצתי | עורך דין + נזילות + אמון |
| סוכני AI צד ג' כמנפיקים מואצלים | conformance + נפח משתמשים |
| שווקים מחוץ ל-IL עם זכויות **מצוטטות** | country packs עם citation אמיתי |
| Settlement chain בייצור בין מוסדות | תלוי באימוץ Mandate |

זה המסלול שבו **שווי שוק** *יכול* להיגזר מ-network + data moat — לא מהבטחת «טריליון».

## מה **לא** צריך לבנות כדי «להגיע מהר»

- Stripe, מטריקות מזויפות, demo outcomes, לוגואים של בנקים בלי רישיון.
- מכרז קבוצתי חי לפני עורך דין ונפח.
- Redis / מיקרו-שירותים לפני שיש עומס מדיד.
- עוד 40 דפי שיווק בלי לולאה סגורה נוספת.

# Product north star (engineering)

**One sentence:** Zakai finishes money recovery **in-app** — detect → Mandate → send → proof → SAVED → share → fee.

## Build order (CEO)

1. **Closed loop** beats new verticals. A letter page without Case+Mandate+send is backlog, not launch.
2. **One next action** beats menus (`nextAction/`, dashboard panel, Money OS context).
3. **Outcome graph** feeds ranking (`StrategyOutcome` → priority, leaks, assistant digest).
4. **Institutions** follow consumer proof (JWKS, verify API) — not the other way around.

## Definition of world-class (acceptance)

- New user: `/money` scan → Case **SENT** in one session.
- Provider reply → inbound → push → **one-tap SAVED**.
- Share + referral without staff.
- Fee only after proof; integer agorot everywhere.

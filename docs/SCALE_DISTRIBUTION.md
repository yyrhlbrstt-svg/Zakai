# Distribution — spread before you optimize (honest)

Trillions in **addressable consumer money friction** exist globally; Zakai revenue is still **fee on documented proof**. Scale is:

```
Surface area × conversion × SENT→SAVED × fee collection
```

Code can widen the first three; founders must turn on SMTP, PayPlus, VAPID, crons.

## Channels shipped in product

| Channel | Mechanism | Attribution |
|---------|-----------|-------------|
| **WhatsApp / native share** | `ShareResult` after wins + `/money` growth strip | `ref=` on signup link when logged in |
| **Refer a friend** | `ReferralCard`, ₪25 credit on friend's first documented save | `signup?ref=` |
| **Partner embed** | `public/embed.js` → `utm_source=embed&utm_campaign=<partner>` | `zakai_partner_ref` cookie → `partnerRef` on user |
| **Paid / social** | `/he/go/cancel?utm_source=cpc&utm_campaign=...` or `?pref=campaign-name` | Same cookie (first-touch) |
| **AI assistants** | `llms.txt` + `utm_source=agent&utm_campaign=agent-<name>` | Same cookie column as embed |
| **Institutions** | JWKS, `/integrations`, opportunity-map API | B2B contracts, not consumer viral |

## Embed paths (high LTV)

Partners pick `data-path` on `#zakai-embed` — see `/partners` and `public/embed.js`.
Default remains `money` (scan → Case). Add paths as agent verticals graduate to `full`.

## CEO spread checklist (no fake metrics)

1. One vertical **paid** at a time (creators + search) with real `/share` cards — amounts from user proof only.
2. Every bank/fintech HR page gets embed + `data-ref` — measure signups in `/he/founder` partnerRef groups.
3. Every SAVED user sees share + referral on dashboard (already) — nudge on `/money` for logged-in sharers.
4. Ship **closed loops** in new markets (`docs/COUNTRY_PACKS.md`) before vanity homepages.

## What “trillion-dollar” means here

- **TAM**: recurring leaks + one-time recoveries across billions of households — real.
- **Zakai revenue**: success fee × documented savings — grows with volume and collection, not with UI hype.
- **Mandate + outcome graph**: compound advantage (institutions + better next action) — long-term moat, not overnight ARR.

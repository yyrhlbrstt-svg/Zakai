# Zakai — Infrastructure doctrine (solo + AI)

## What "trillion path" actually means

Not a slide number. A **protocol layer** consumers and institutions both need:

1. **Consumer authority** — machine-verifiable mandate (scopes, JWKS, revocation).
2. **Documented outcome** — before/after savings ledger (only billable success).
3. **Closed automation** — analyze → act → follow up → prove → share, without a call center.
4. **Distribution** — viral proof ("I saved ₪X") + referrals, not paid ads dependence.
5. **Two-sided gravity** — providers eventually verify mandates because enough users send them.

## What we refuse

- Promising human callbacks when there is no team.
- Charging before documented saving.
- Impersonating the customer.
- Fake traction numbers.

## Near-term product law

Every feature must either:
- **Find** money (detect leak),
- **Act** (letter / negotiation / filing path),
- **Prove** (ledger),
- or **Spread** (share / referral).

If it does none of these, it does not ship.

- [ ] AI keys live (assistant + OCR)
